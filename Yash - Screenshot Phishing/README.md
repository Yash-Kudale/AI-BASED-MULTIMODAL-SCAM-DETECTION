# Yash - Screenshot Phishing Detection

## Overview
This project detects potential phishing websites by analyzing website screenshots using deep learning.

## Project Contents
- `dataset/` — Legitimate and phishing screenshot datasets.
- `models/` — Trained screenshot classification models.
- `notebook/` — Jupyter notebooks used for development and evaluation.
- `results/` — Model evaluation results and reports.

## Model
MobileNetV2 with fine-tuning.

## Purpose
Academic cybersecurity research and educational use.
