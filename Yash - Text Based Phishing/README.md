# Yash - Text Based Phishing Detection

## Overview
This project detects potentially suspicious phishing or spam-type messages using machine learning and text processing.

## Project Structure
- `dataset/` — Text and email datasets.
- `models/` — Trained Logistic Regression model and TF-IDF vectorizer.
- `notebook/` — Jupyter notebooks for preprocessing, training, and evaluation.
- `results/` — Model evaluation metrics and reports.

## Model
TF-IDF feature extraction with Logistic Regression.

## Purpose
Academic cybersecurity research and educational use.
