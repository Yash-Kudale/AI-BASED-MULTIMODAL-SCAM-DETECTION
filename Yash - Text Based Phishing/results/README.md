# Text-Based Phishing Detection Results

This folder contains the evaluation results and performance metrics for the text-based phishing detection model.

## Evaluation
- Validation accuracy: 99.17%
- Held-out test accuracy: 99.33%
- Classification model: Logistic Regression
- Text representation: TF-IDF

Note: These results were obtained using a sampled dataset derived from CEAS_08 and should not be interpreted as guaranteed real-world detection performance.
