# Text-Based Phishing Detection Models

This folder contains the trained machine learning model and text feature extraction files used by the project.

## Model Files
- `text_phishing_logistic_regression.pkl` — Trained Logistic Regression classifier.
- `text_phishing_tfidf_vectorizer.pkl` — Fitted TF-IDF vectorizer.

Both files are required to load the trained model and make predictions on new text.
